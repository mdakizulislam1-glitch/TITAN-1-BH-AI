01 — RESEARCH

Scientific Image Restoration

TITAN-1 studies a general scientific image-restoration problem under controlled computational conditions.

y = H(x) + n

x

Underlying clean or latent scientific image.

H

Degradation or instrument-response operator.

n

Noise or measurement disturbance.

The current TITAN-1 benchmark evaluates this problem using controlled synthetic scientific-image structures.

03 — MODEL

Lightweight CNN Architecture

The canonical TITAN-1 model is intentionally compact and designed for reproducible experimentation.

1 → 32 → 32 → 16 → 1

Model

  • 4 convolutional layers
  • 3 × 3 kernels
  • ReLU activations
  • Final Sigmoid activation
  • 14,337 trainable parameters

Training

  • MSE loss
  • Adam optimizer
  • Learning rate: 0.001
  • Batch size: 32
  • 30 training epochs

07 — SCIENTIFIC POSITION

What TITAN-1 Does — and Does Not — Claim

Currently Supported

  • Controlled synthetic scientific-image denoising
  • Unseen morphology evaluation
  • Multiple noise-family experiments
  • Controlled PSF / blur experiments
  • Resolution-shift evaluation
  • Reproducible software foundation

Not Yet Established

  • Real EHT TITAN-1 validation
  • Astrophysical parameter inference
  • NASA / ESA / CERN validation
  • Production telescope pipeline
  • Commercial validation
  • Universal denoising superiority
  • New-physics discovery
